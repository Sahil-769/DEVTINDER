## 🛠️ Getting Started

To run any of the examples or projects locally:

### Prerequisites
* [Node.js](https://nodejs.org/) (v18+ recommended)
* [Git](https://git-scm.com/)

### Installation & Running

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Install dependencies** *(if a folder contains a `package.json`)*
   ```bash
   npm install
   ```

3. **Run a script**
   ```bash
   node path/to/file.js
   ```
